# 入口路由注册表（挂接对账唯一事实源）

维护纪律（先读再改）：

- **新入口先入表，再写触发表散文**——SKILL.md 意图识别表/触发表的新行，必须先在本表登记（指向=文件路径::锚词 两段式，锚词须能在该文件 grep 到），否则 lint「挂接对账」红。
- 本表是 lint「挂接对账」检查的唯一事实源，对应 JVM 可达性模型：**本表 = root set，指向/载体列 = 边，lint = 可达性遍历**——指向的文件必须存在、锚词必须 grep 得到（悬空=红）；「加载面=是」的行，description锚 必须出现在 SKILL.md 的 description 行（双面对账）；表二载体的纪律锚词必须落在文件里（死规则=红）。
- 锚词选**稳定关键词**（节标题/专有机制名），不选易漂移的行文措辞；改文件时挪动了锚词，必须同步改本表。
- 环境变量 `TF_ENTRY_ROUTES` 可覆盖本表路径（测试用）；缺失或两表不可解析 = lint 红。
