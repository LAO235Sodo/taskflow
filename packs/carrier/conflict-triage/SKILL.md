# conflict-triage — 写集冲突分级

能力契约：输入=两（或多）任务的写集（各自 spec「改动文件集合声明」）；输出=重叠面+冲突分级+处置建议。

## 执行清单

1. **输入**：各任务写集（文件/目录清单；机械辅助 `node <taskflow>/scripts/tf.mjs overlap <task-id>` 可用则跑）。
2. **重叠面枚举**：两两求交（目录前缀算重叠——父目录改动覆盖子路径），列出共享文件/目录。
3. **冲突分级**（每对重叠逐项判）：
   - 可并行：写集不相交，或相交但读写位正交（不同函数/不同节）——须给出正交证据；
   - 需排序：同一文件先后改（后者的基线含前者）——写明顺序与等待方；
   - 需拆分：共享单元语义耦合（同函数/同口径）——合并进一个任务或抽出公共子任务。
4. **灰区默认升语义**：无法机械证明正交 = 按需排序处理，禁当场猜「应该没事」。
5. **输出**：重叠表+分级结论+处置建议（排序链/拆分边界），呈用户拍板后执行；分叉呈报禁自选边。

## 边界

- 只分级不解冲突（解合并冲突是另一技能的事）；分级结论须可证伪（重叠清单可复核）。
