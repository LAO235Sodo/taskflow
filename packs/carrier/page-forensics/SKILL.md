# page-forensics — 页面级故障取证

能力契约：输入=页面级故障现象（哪页、什么表现）；输出=页面↔接口映射表+取证清单。纪律：页面级问题先全量取证建映射，禁凭话语猜单接口开查。

## 执行清单

1. **输入**：现象描述（页面/表现/复现路径）+ 可用工具（浏览器/抓包/日志）。
2. **页面↔接口映射**（两通道合围）：
   - 运行时通道：打开页面抓全量网络请求（URL/方法/状态码/耗时/响应摘要）；
   - 代码面通道：grep 页面源码的 API 调用枚举（含条件分支里的请求）；
   - 两通道差集=未触达或漏枚举，逐个标注。
3. **取证清单**（每接口过）：
   - 请求是否发出/状态码/响应体结构与样本；
   - 前端消费点（哪个组件读哪个字段）；
   - 视觉面：渲染结果截图/DOM 采样（可程序采样的禁目测定案）。
4. **定位输出**：映射表+异常点标注（失败接口/字段缺失/前端消费错），交诊断纪律排假设（3~5 个排序假设呈报）。
5. **输出落档**：映射表落 `.taskflow/<id>/findings.md` 或证据包（`tf.mjs diagnose <id>`）。

## 边界

- 只取证不修；证据可复核（接口清单与截图随档）。
