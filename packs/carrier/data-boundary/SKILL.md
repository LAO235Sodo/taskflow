# data-boundary — 数据边界枚举

能力契约：输入=改动集；输出=涉数据管道边界枚举+上下游影响面。

## 执行清单

1. **输入**：改动集+数据流描述（哪条管道：入库/统计/推送/导出/展示）。
2. **边界枚举**（逐管道列出）：
   - 上游：数据从哪来（写入方/采集点/外部依赖）；
   - 下游：数据被谁消费（报表/推送/导出/二次计算）；
   - 边界点：管道的每个交接处（表/队列/缓存/文件/接口响应）。
3. **五维检查**（每个边界点过一遍，空态显式标注）：
   - 量：空集/单条/海量分页；
   - 时间：无数据时段/时区/延迟到达（迟到数据）；
   - 值：空值/默认值/非法值/单位与位序；
   - 一致性：跨管道口径是否同源（同指标两处计算=分叉）；
   - 展示：空态给用户看什么（禁白屏/禁拼凑占位）。
4. **三禁**：算了不传（后端算了前端拿不到）/ 传空容器（数组恒空）/ 没数据硬凑（假数据冒充真值）。
5. **输出**：边界枚举表+五维结论，落 spec「边界与影响面」；涉及存量字段口径变更 → 同步走数据模型对照（jvm-data 包，如启用）。

## 边界

- 只枚举与标注，不替用户拍口径；口径冲突呈报。
