# jvm-data 包 — 数据模型对照门

> 能力包（v3.0.0）：数据结构/实体/契约方向的门族。仅当项目 profile `packs.jvm-data=true` 时加载。
> 安装产物：`node <skill目录>/scripts/tf.mjs mech install DATA_MODEL_GATE`（提取器 + 门脚本）。

## 规则全文（DATA_MODEL_GATE，原硬规则 28）

⓪ **全任务分诊（成本一行）**：立项必答「本任务动不动数据模型」，spec 落 `数据模型分诊：涉及|不涉及——理由` 行（判定依据 = 预期改动文件集合 × 门脚本谓词初筛 + 需求词信号「加字段/加表/改含义/改单位/改契约」+ 编排层判断）；不涉 = 一行理由免全流程；**分诊漏判由收尾谓词兜底**（分诊说不涉而 diff/资产命中数据资产 = 门红）。

① **触发三类**：实体（表/列/注解）、契约（对外 JSON 字段/枚举值）、存量字段口径（含义/单位/位序变更）——机械下界 = 门脚本谓词（.sql/迁移目录/实体目录路径层 + 实体注解/CREATE·ALTER TABLE 内容层），编排层判定补上界（DTO 纯改名等谓词漏网形态）。

② **产物三件**：提取器 `extract-data-model.js`（SQL DDL 面 + 注解实体面 → 表清单/实体↔DDL 列级映射/同名表多源/表间依赖四件事实）+ 真源 `docs/data-model/`（**lock-file：内容只能由提取器再生，手工编辑真源产物=违规**；拍板日志 `DATA_MODEL_DECISIONS.md` 只增不改；单源双形态——机器 JSON + 人读渲染同次产出）+ spec「数据模型对照表」拍板（现状列只认提取产物+源码锚，禁凭记忆转述；拍板列未填禁动工）。

③ **收尾行**：涉数据条目必含 `数据模型：<对照表/提取 JSON 路径>；同步：<≥1 项同步动作>；真源：已刷新`；涉 DDL 追加「DDL：」子段（其余定义处处置+迁移）；`validate-data-model-gate.sh --spec` 五检查挂 merge 阶段三。

## 事故档案

- 本仓实证：decisions/ 口径类占近半、同一字段语义返工到第 7 轮才沉淀、主工作流表一族在两份 schema 文件双源定义漂移 → 前端视觉轴有四道机械门而数据轴零道，本门补齐（2026-11-01 拍板）。
